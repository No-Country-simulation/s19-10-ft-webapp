# Notepad AI

![logo-title](https://github.com/user-attachments/assets/3d092e55-1e87-4b59-bf78-1e63b5f56e0c)

**Notepad AI** es una plataforma de notas potenciada por inteligencia artificial, diseñada especialmente para estudiantes. Combina la simplicidad de un bloc de notas tradicional con herramientas avanzadas de IA para mejorar el aprendizaje y la organización académica.

---

## ✨ Características Principales

- **Notas Inteligentes:** Crear y editar notas de manera intuitiva.
- **Resúmenes Automáticos:** Extrae los puntos clave de textos largos.
- **Generador de Preguntas:** Ideal para preparar exámenes y autoevaluaciones.
- **Organización Eficiente:** Sistema de categorías y etiquetas.
- **Interfaz Intuitiva:** Diseño moderno y amigable.

## 🔄 Instalación y Configuración

### Requisitos Previos

- Node.js (v16 o superior).
- .NET SDK (compatible con el backend).
- Docker (opcional para entorno estandarizado).

### Pasos para la Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/notepad-ai.git](https://github.com/No-Country-simulation/s19-10-ft-webapp
   cd s19-10-ft-webapp
   ```

2. Instala las dependencias:
   - **Frontend:**
     ```bash
     cd frontend
     npm install
     ```
   - **Backend:**
     ```bash
     cd backend
     dotnet restore
     ```

3. Configura las variables de entorno:
   - Crea un archivo `.env` en el directorio correspondiente con las variables necesarias para conectarte a APIs y bases de datos.

4. Inicia la aplicación:
   - **Frontend:**
     ```bash
     npm run dev
     ```
   - **Backend:**
     ```bash
     dotnet run
     ```
